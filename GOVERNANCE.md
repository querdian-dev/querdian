# Governance

Querdian is a vendor-neutral, community-driven project.

## Roles

- **Contributors** — anyone who submits issues, pull requests or reviews.
- **Maintainers** — listed in [MAINTAINERS.md](MAINTAINERS.md). They review and merge changes,
  cut releases and handle security reports.

## Decision making

- Changes are made by pull request; a maintainer other than the author must approve.
- Design-level changes (anything touching `PLAN.md`) require approval from a majority of
  maintainers.
- Security-relevant behaviour is never decided by guessing: open an issue and resolve it
  explicitly first.
- Disagreements are resolved by consensus; failing that, by a simple majority vote of maintainers.

## Becoming a maintainer

Sustained, high-quality contributions plus a nomination from an existing maintainer, approved by
a majority of maintainers.

## Licensing and provenance

All code is Apache-2.0 and contributions require a DCO sign-off. The clean-room rules in
[CONTRIBUTING.md](CONTRIBUTING.md) apply to every contributor.

## Foundation

The project intends to apply to the CNCF Sandbox once it has adopters; the GitHub organization
will add CNCF as an owner upon acceptance.
